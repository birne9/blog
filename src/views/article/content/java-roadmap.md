## 为什么需要一份路线

你已经有一套完整的前端能力: H5、PC、小程序都会, Vue、React、TypeScript 都熟。现在转 Java 后端, 最大的风险不是"学不会", 而是"东一榔头西一棒槌": 今天刷两集视频, 明天抄一段代码, 三个月后发现自己还是只会复制粘贴, 遇到报错还是慌。这份路线把 12 周拆成四个阶段, 每周 5 小时, 学完之后的目标很具体: 能看懂公司 cms-center 的代码调用链, 能独立写一个带数据库的 Spring Boot 接口。

## 三个原则: 视频搭骨架、AI 填血肉、项目当考场

视频搭骨架。B站课程的价值在于"顺序": 什么先学什么后学, 概念之间的依赖关系是什么, 老师已经替你排好了。你自己啃文档最大的问题不是看不懂, 而是不知道下一步该学什么, 东看一段西看一段, 永远拼不出完整的知识体系。所以骨架必须来自成体系的视频课。

AI 填血肉。有了骨架, 你才知道该问什么。听不懂的概念让 AI 用前端类比讲给你听: Feign 就是 axios, Redis 就是 localStorage 加过期时间, Nacos 就是前端的远程配置中心。遇到报错把堆栈丢给 AI 帮你定位。但反过来, 没有骨架就直接问 AI, 得到的答案你无法判断对错, 效率反而低。

项目当考场。每周的实操任务是小考, 最后三周的项目是大考。看得懂不等于写得出来, 写得出来不等于调得通, 只有项目能验证真实水平。你现有的前端能力就是靠项目练出来的, 后端同理。

> 每周 5 小时建议这样分: 2.5 小时视频 + 2 小时实操 + 0.5 小时整理笔记。实操时间宁可多, 不可少。

## 四阶段总览

第 1-4 周是 Java 语言基础, 借着你写 JS/TS 的经验快速过, 重点放在"类型"和"面向对象"上。第 5-6 周是 SQL 与数据库, 后端日常一半的工作是写 SQL 和调 SQL。第 7-9 周是 Spring Boot 核心, 从跑起来到写出一个可联调的接口。第 10-12 周是全栈实战加公司项目, 用一个小项目把前面所学串起来, 再回到 cms-center 里读真实代码。

配套阅读就是本站已有的四大系列: Java 基础(一)-(四)、SQL 基础(一)-(五)、Spring Boot 入门(一)-(五)、全栈实战(一)-(五)。视频用来学骨架, 这些文章用来当讲义复习, 视频里漏掉的细节文章里都有。

## 第 1 周: Java 环境与基础语法

目标: 装好 JDK 和 IDEA, 写出第一个程序, 掌握变量、数据类型、运算符和流程控制。

### 视频学习(2.5 小时)

B站任意一套 Java 入门课(推荐尚硅谷宋红康版), 看前 30 集左右: JDK 安装与 IDEA 使用、HelloWorld、注释、变量与数据类型、运算符、流程控制。你的前端经验可以大量复用: if/switch/for/while 和 JS 几乎一样, 这周的重点只有两个字——类型。Java 是强类型, 变量声明时类型就定死了, int 和 double 不能随便混, 这和 TS 很像但更严格。

### 实操任务(2 小时)

把你在 JS 里写过的逻辑用 Java 重写一遍: 一个判断闰年的方法, 一个九九乘法表, 一个求数组最大值的方法。重点体会: 每个变量必须先声明类型, 方法的参数和返回值也必须带类型。

> 看完视频后回来看本站「Java 基础(一):基础语法」当复习讲义。

## 第 2 周: 面向对象

目标: 掌握类与对象、封装、继承、多态、抽象类与接口。这是 Java 和 JS 差别最大的一周, 也是后面一切框架的地基。

### 视频学习(2.5 小时)

继续看入门课的面向对象部分, 大概 40 集左右: 类与对象、成员变量与方法、构造器、封装、继承、多态、抽象类与接口。类就是你的 class 组件, interface 就是 TS 的 interface, 多态可以类比 Vue 组件的 props 传入不同类型实例。听不懂的多态部分让 AI 用前端例子再讲一遍, 这是 Java 第一道真正难的门槛。

### 实操任务(2 小时)

写一个内存版的学生管理系统: Student 类(姓名、学号、成绩), 用一个 List 存数据, 实现增删改查四个方法, 再写一个测试类调用它们。可以故意设计一个子类(比如研究生类继承学生类), 体会多态。

> 复习讲义: 本站「Java 基础(二):面向对象」。

## 第 3 周: 常用 API 与集合框架

目标: 掌握 String、集合框架(ArrayList、HashMap)、异常处理, 这些是日常写业务代码最高频的东西。

### 视频学习(2.5 小时)

看入门课的常用类部分: String 与 StringBuilder、包装类、ArrayList 与 HashMap 的常用方法、Collections 工具类、异常体系(try-catch、throw、throws、自定义异常)。HashMap 就是 JS 的 Map, 异常就是 throw 和 try-catch, 这周的概念你会觉得很亲切。

### 实操任务(2 小时)

用 HashMap 统计一篇文章的词频: 读取一段文本, 分词后统计每个词出现次数, 按次数排序输出前 10 名。再给词频统计方法加上参数校验, 空文本时抛一个自定义异常, 体会异常处理的价值。

> 复习讲义: 本站「Java 基础(三):常用API与进阶」。

## 第 4 周: 泛型、Stream、注解、反射 + Maven

目标: 掌握泛型与 Stream, 认识注解和反射, 并装上 Maven——这是进入 Spring Boot 世界的最后一块拼图。

### 视频学习(2.5 小时)

这周内容散, 可以各看一点: 泛型(直接类比 TS 泛型, 半小时就能懂)、Lambda 与 Stream(类比 JS 数组的 map/filter/reduce)、注解(类比装饰器)、反射(类比 JS 的 Reflect)。最后看 Maven 部分: 安装 Maven、坐标与仓库、pom.xml 结构——pom.xml 就是 package.json, 依赖坐标就是 dependencies。

### 实操任务(2 小时)

用 Stream 重写第 3 周的词频统计, 感受声明式写法的爽快。然后创建一个 Maven 项目, 在 pom.xml 里引入一个第三方库(比如 commons-lang3), 调它的方法, 理解"依赖从仓库下载"的机制。顺带把 IDEA 的 Maven 配置好, 换成阿里云镜像, 避免后续下载依赖卡住。

> 复习讲义: 本站「Java 基础(四):泛型、Stream与反射」。

## 第 5 周: SQL 基础与查询

目标: 掌握关系模型和 SELECT 查询, 会用 Navicat 连库。后端日常一半的工作是 SQL, 这周开始往"能干活"的方向走。

### 视频学习(2.5 小时)

看任意一套 MySQL 入门课的上半部分: 数据库与表的概念、数据类型、建表语句、SELECT、WHERE 条件、ORDER BY 排序、LIMIT 分页、聚合函数(GROUP BY/HAVING)。表就是前端的列表数据源, 主键就是数组的索引, 外键就是关联关系的 id。

### 实操任务(2 小时)

用 Navicat 连上开发库, 先只读地看表结构, 熟悉公司的表命名习惯。然后自己建一张练习表(比如商品表), 插入几十条数据, 写出至少 20 条不同的查询: 各种条件的组合、排序、分页、聚合统计。SQL 没有捷径, 就是多写。

> 复习讲义: 本站「SQL 基础(一):关系模型与MySQL」和「SQL 基础(二):查询数据」。

## 第 6 周: 多表连接、增删改与事务索引

目标: 掌握多表连接、增删改、事务和索引。这周学完, 你就能读懂公司 Mapper 里 90% 的 SQL 了。

### 视频学习(2.5 小时)

看 MySQL 入门课的下半部分: INNER JOIN 与 LEFT JOIN、INSERT/UPDATE/DELETE、事务与 ACID、四种隔离级别、索引原理与最左前缀、EXPLAIN 分析。事务可以类比前端的"批量操作要全部成功才算成功", 索引可以类比"给数组建个哈希表加快查找"。

### 实操任务(2 小时)

建两张有关联的表(比如商品表和分类表), 练习各种连接查询, 搞清楚 INNER JOIN 和 LEFT JOIN 结果的区别。开两个查询窗口演示事务: 一个窗口开启事务改了数据不提交, 另一个窗口看得到看不到。最后给练习表加索引, 用 EXPLAIN 对比加索引前后的执行计划。

> 复习讲义: 本站「SQL 基础(三):多表连接与增删改」、「SQL 基础(四):事务与隔离级别」、「SQL 基础(五):索引优化」。

## 第 7 周: Spring Boot 起步与 IoC

目标: 跑起来第一个 Spring Boot 项目, 理解 IoC 与依赖注入。从这周起, 你才真正进入后端框架的世界。

### 视频学习(2.5 小时)

看一套 Spring Boot 入门课的前几章: 什么是 Spring Boot、创建项目、启动流程、约定优于配置、IoC 容器与 Bean、组件注解与依赖注入、构造器注入。IoC 可以类比成: 以前你手动 new 组件再传进去, 现在容器帮你创建好直接注入, 就像前端框架帮你管理组件实例一样。这套思想是 Spring 的灵魂, 一定要理解透。

### 实操任务(2 小时)

用 Spring Initializr 创建一个项目, 跑起来一个 /hello 接口, 用浏览器访问成功。然后自己加一个 Service 类, 通过构造器注入到 Controller 里使用, 体会"不用 new"的感觉。注意版本差异: 你的公司是 JDK11 加 Boot 2.x, 视频可能是 JDK17 加 Boot 3, 大思路完全一样, 个别依赖名不同(比如 web starter 改过名), 遇到报错让 AI 按你公司的版本改。

> 复习讲义: 本站「Spring Boot(一):起步与自动配置」和「Spring Boot(二):IoC与依赖注入」。

## 第 8 周: REST 接口开发

目标: 掌握注解式接口开发, 写出第一个完整的 CRUD。这是后端开发最核心的日常技能。

### 视频学习(2.5 小时)

看 Spring Boot 入门课的 Web 开发部分: @RestController、@GetMapping/@PostMapping/@PutMapping/@DeleteMapping、参数的三种来路(@RequestParam、@PathVariable、@RequestBody)、Controller/Service 分层思想、简单参数校验。这些注解就是前端的路由和请求封装, 你会有很强的既视感。

### 实操任务(2 小时)

写一个学生成绩的 CRUD 接口(先用内存 List 存数据, 下周再接数据库): 新增、按 id 查、查全部、改成绩、删除, 全部用 Postman 自测一遍。体会分层: Controller 只管接收请求和返回, Service 管业务逻辑, 数据访问交给下一层。

> 复习讲义: 本站「Spring Boot(三):REST接口开发」。

## 第 9 周: MyBatis + 统一返回与全局异常

目标: 接上 MySQL, 掌握 MyBatis, 并给接口套上统一返回和全局异常。这周学完, 你写出的接口就是公司标准的样子了。

### 视频学习(2.5 小时)

看 Spring Boot 入门课的持久层部分: 数据源配置、MyBatis 的 Mapper 接口与 XML、#{} 与 ${} 的区别(防注入)、动态 SQL(if/foreach)。再看统一返回与全局异常: Result 外壳、@RestControllerAdvice、@ExceptionHandler。公司 cms-center 里就是这一套, 学完这周你就能对上号。

### 实操任务(2 小时)

把第 8 周的学生成绩项目从内存版改成 MySQL 版: 建表、配置数据源、写 Mapper 接口和 XML、联调通过。然后套上 Result 统一返回和全局异常处理, 故意传一个非法参数, 看全局异常怎么兜底。到这里, 你已经有了一个"正经"的后端项目。

> 复习讲义: 本站「Spring Boot(四):MyBatis连MySQL」和「Spring Boot(五):统一返回与全局异常」。

## 第 10 周: 全栈实战之需求与后端

目标: 自己定一个小需求, 从设计到后端实现完整走一遍。前三周是学零件, 这周开始组装整车。

### 视频学习(1 小时)

这周视频大幅减量, 只补看实战课里"需求分析和表设计"的部分, 看看老师是怎么把一个想法拆成功能清单和表结构的。其余时间全部留给动手。

### 实操任务(3.5 小时)

自己定一个想做的小项目(记账本、待办清单、书架管理都行), 完成三件事: 写出功能清单(有哪些页面、哪些操作)、设计数据表(字段、类型、关联)、约定接口(路径、方法、参数、返回结构)。然后按约定把后端全部实现, 用 Postman 把每个接口都调通。

> 复习讲义: 本站「全栈实战(一):需求与接口设计」和「全栈实战(二):Spring Boot后端实现」。

## 第 11 周: 全栈实战之前端对接

目标: 用前端调自己写的后端, 打通完整链路。这周是你的主场, 也是检验后端水平的照妖镜。

### 视频学习(1 小时)

补看实战课里前端对接的部分: 跨域怎么处理、Vite 代理怎么配、请求封装怎么做。这些你本来就熟, 快速过一遍即可。

### 实操任务(3.5 小时)

用 Vue(或 React)给第 10 周的项目写前端: 列表页、表单页、增删改查操作全部接上真实后端。完整链路走通之后, 回头检查接口设计是否合理: 有没有字段多余、有没有一次页面要发很多请求、报错提示是否友好。前端视角就是你最大的优势, 用你自己的项目把接口打磨一遍, 这比看十集视频都值。

> 复习讲义: 本站「全栈实战(三):Vue3前端实现」和「全栈实战(四):React前端实现」。

## 第 12 周: 部署与公司项目实战

目标: 学会打包部署, 然后回到公司代码里实战。12 周计划的终点, 是你开始用"项目当考场"的方式持续成长。

### 视频学习(1 小时)

看实战课的部署部分: jar 打包、Nginx 静态托管与反向代理、常见坑。对前端来说 Nginx 不陌生, 重点看反向代理到后端服务这一段。

### 实操任务(3.5 小时)

把自己的项目打包成 jar, 部署起来, 前端 dist 挂到 Nginx, 反向代理到后端, 用域名或 IP 完整访问一遍。然后进入公司实战: 从 cms-center 里挑一个你已经熟悉的业务(比如之前排查过的广告接口), 从 Controller 一路读到 Service、Feign 调用、再到 Mapper 里的 SQL, 画出完整的调用链。以后每次遇到线上问题, 都按这个链条往下读, 三个月后你对公司代码的熟悉度会远超同龄人。

> 复习讲义: 本站「全栈实战(五):打包部署Nginx」。

## 一些注意事项

12 周不是死规定。某一周卡壳了, 就多花一周; 某两周内容顺, 就加速。唯一不能省的是每周的实操任务——宁可少看一集视频, 也要把代码写完, 因为写代码的时间才算数。

关于版本: 公司是 JDK11 加 Spring Boot 2.x 加 Spring Cloud, 视频教程很多是 JDK17 加 Boot 3。两者的思想完全一致, 个别类名和依赖名有差异, 遇到这类报错直接让 AI 按你公司的版本修正即可, 不必纠结。

12 周之后, 不是"学完了", 而是"入门了"。下一步的方向是中间件(Redis、Kafka)和 Spring Cloud 全家桶(Nacos 配置中心、Feign 调用、网关), 这些东西在公司真实项目里用起来, 学得最快。

> 附: 每周日的固定动作——花 10 分钟把这周学到的东西整理成一篇短文, 就写在本博客。输出是最好的复习, 三个月后你会收获 12 篇文章和一套自己的知识体系。
