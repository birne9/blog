## 数制与编码

计算机底层只有 0 和 1,一切数据最终都是**二进制**。考试常考**四种进制**:二进制 B(Binary)、八进制 O(Octal)、十进制 D(Decimal)、十六进制 H(Hexadecimal)。**进制互转是必拿分**,要做到心算秒答。

### 进制互转

任意进制转十进制用**按权展开法**:每位数字乘以基数的相应次幂再求和。

```text
二进制 1011.01 转十进制:
1×2^3 + 0×2^2 + 1×2^1 + 1×2^0 + 0×2^-1 + 1×2^-2
= 8 + 0 + 2 + 1 + 0 + 0.25
= 11.25
```

十进制转二进制:整数部分**除 2 取余、倒序排列**;小数部分**乘 2 取整、正序排列**。

```text
45 转二进制:
45 ÷ 2 = 22 余 1
22 ÷ 2 = 11 余 0
11 ÷ 2 = 5  余 1
5  ÷ 2 = 2  余 1
2  ÷ 2 = 1  余 0
1  ÷ 2 = 0  余 1
余数倒序读出: 101101, 即 45 = 101101B
```

二进制与八进制、十六进制互转走**分组路线**:从小数点向两边,**三位一组对应八进制,四位一组对应十六进制**,不够补 0。

```text
10110101B 转十六进制: 1011 0101 → B 5, 即 B5H
10110101B 转八进制:   010 110 101 → 2 6 5, 即 265O
```

> 考点提示:选择题常给一个十六进制数让转十进制,或问某二进制数对应几位十六进制。记住一组对应关系——**四位二进制恰好是一位十六进制**,0 到 15 依次对应 0 到 F,分组后直接拼即可,省去中间换算。

### 原码、反码、补码、移码

机器数有**四种编码**,设机器字长 8 位,以 +45 和 -45 为例:

```text
+45: 原码 00101101   反码 00101101   补码 00101101  (正数三码相同)
-45: 原码 10101101   反码 11010010   补码 11010011
```

规则:**正数的原码、反码、补码完全相同**;负数的反码是原码**符号位不变、数值位按位取反**,补码是**反码末位加 1**。**移码是补码的符号位取反**,-45 的补码是 11010011,移码就是 01010011,移码主要用作浮点数的**阶码**。

8 位字长下各编码的表示范围:原码 -127 到 +127,反码 -127 到 +127,**补码 -128 到 +127**,移码 -128 到 +127。原码和反码中 0 有 +0、-0 两种表示,**补码中 0 的表示唯一**,省下的一个编码给了 -128,所以**补码能多表示一个负数**。

> 考点提示:表示范围是高频考点。记住 **n 位补码的范围是 -2^(n-1) 到 2^(n-1)-1**,原码和反码两端各少一个。题目问 8 位补码能表示的最小值,答案是 **-128** 而不是 -127,这是经典陷阱。

### 补码加减法与溢出判断

补码的价值在于**把减法变成加法**:X - Y = X + (-Y) 的补码,**符号位直接参与运算**,最高位产生的进位丢弃。

```text
计算 45 - 30 (8 位补码):
45  的补码  00101101
-30 的补码  11100010   (30 = 00011110, 取反 11100001, 加 1 得 11100010)
相加: 00101101 + 11100010 = 1 00001111
最高位的进位丢弃, 结果 00001111 = 15, 正确
```

溢出只可能发生在**同号相加**:两个正数相加得到负数,或两个负数相加得到正数,即为溢出,**异号相加永不溢出**。

```text
计算 64 + 65 (8 位补码, 表示范围 -128 ~ 127):
64 的补码   01000000
65 的补码   01000001
相加结果    10000001 = -127
两个正数相加得到负数, 发生溢出
```

判断方法:**双符号位法**中结果的两个符号位不同则溢出;**单符号位法**看数值最高位向符号位的进位与符号位向外的进位是否一致,**不一致即溢出**。

## 浮点数

定点数的小数点位置固定,表示范围有限;浮点数让小数点浮动,结构是阶码加尾数:**N = M × R^E**。其中 **E 是阶码**(整数,常用移码表示),**M 是尾数**(纯小数,常用补码表示),**R 是基数(隐含为 2,不占存储位)**。

```text
浮点数一般格式:
[数符] [阶码] [尾数]
阶码的位数决定能表示的范围, 尾数的位数决定精度
```

规格化:为了充分利用尾数的有效位,规定**尾数最高数值位必须为 1**,即尾数 M 的绝对值大于等于 1/2 且小于 1。尾数左移一位阶码减 1 叫**左规**,右移一位阶码加 1 叫**右规**。

**IEEE 754** 标准:单精度浮点 32 位 = **1 位符号 + 8 位阶码(移码,偏置 127)+ 23 位尾数**,尾数隐含最高位的 1,实际有 24 位有效位;双精度 64 位 = **1 位符号 + 11 位阶码 + 52 位尾数**。

浮点数加减运算必须先**对阶**:**小阶向大阶看齐**,小阶那个数的尾数右移。因为尾数右移丢失的是低位,至多损失精度;若让大阶的尾数右移,丢失的是高位,直接出错。

```text
X = 0.1101 × 2^010, Y = 0.1011 × 2^100, 求 X + Y
1. 对阶: X 的阶码 010 (十进制 2) 小于 Y 的 100 (十进制 4)
   X 的尾数右移两位: X = 0.001101 × 2^100
2. 尾数相加: 0.001101 + 0.101100 = 0.111001
3. 结果: 0.111001 × 2^100, 最高位已是 1, 无需再规格化
```

类比前端:JS 的 number 就是 **IEEE 754 双精度浮点**——0.1 + 0.2 不等于 0.3、Number.MAX_SAFE_INTEGER 是 **2^53 - 1**(52 位尾数加隐含的 1),前端天天踩的这些坑,根子全在这一节。阶码相当于科学计数法里的指数,尾数相当于有效数字,大数精度丢失就是 52 位尾数装不下全部有效数字的结果。

## 校验码

校验码通过在有效数据上添加**冗余位**来发现或纠正错误。衡量能力的指标是**码距**:两个合法码字之间对应位不同的最少位数,**码距越大,检错纠错能力越强**。

### 奇偶校验

在数据位末尾加 1 位校验位。**奇校验**让整个码字中 1 的个数为奇数,**偶校验**让 1 的个数为偶数。

```text
数据 1011001 (含 4 个 1, 已是偶数)
偶校验码: 1011001 0   (补 0, 保持 1 的个数为偶数)
奇校验码: 1011001 1   (补 1, 凑成 1 的个数为奇数)
```

奇偶校验**只能发现奇数个位同时出错**,不能定位错误位置,**也不能纠错**,优点是实现成本极低。

### CRC 循环冗余校验

**CRC**(Cyclic Redundancy Check)用**模 2 除法**生成校验位。模 2 运算就是**异或**:加减都不进位、不借位,相同得 0,不同得 1。

```text
信息位 1100, 生成多项式 G(x) = x^3 + x + 1
G(x) 对应二进制: 1011  (x^3 项、x 项、常数项的系数为 1)
1. 信息位后补 r 个 0 (r = 多项式最高次数 = 3): 1100000
2. 模 2 除法 1100000 ÷ 1011:
   1100 ⊕ 1011 = 0111, 落下一位得 1110
   1110 ⊕ 1011 = 0101, 落下一位得 1010
   1010 ⊕ 1011 = 0001, 落下一位得 0010
   余数 010 (位数不足前面补 0)
3. 发送码字 = 信息位 + 余数: 1100 010
4. 接收方用收到的 1100010 除以 1011, 余数为 0 则传输正确
```

CRC **检错能力强、硬件实现简单**,但**只能检错不能纠错**,广泛用于网络通信和存储。

### 海明码

**海明(Hamming)码能纠正一位错**。设数据位 n 位、校验位 k 位,必须满足不等式:**2^k ≥ n + k + 1**。

```text
n = 4 时求 k:
k = 2: 2^2 = 4 < 4 + 2 + 1 = 7, 不够
k = 3: 2^3 = 8 ≥ 4 + 3 + 1 = 8, 满足
结论: 4 位数据需要 3 位校验位, 海明码共 7 位
```

原理:k 位校验位能表示 2^k 种状态,需要覆盖 n+k 个位置各错一次外加无错,共 **n+k+1** 种情况。校验位安插在 **2 的幂次位置(第 1、2、4、8 位)**,每个校验位分管一批位置的奇偶性;出错时各校验位的检查结果拼成一个二进制数,直接指出出错位置,取反即可纠正。

> 考点提示:三种校验码的能力对比是送分题——**奇偶校验检奇数位错但不纠错,CRC 检错不纠错,海明码能纠一位错**。海明码几乎每次必考不等式 **2^k ≥ n+k+1**,把选项里的 k 逐个代入验算即可,不用背表。

## CPU 与指令系统

CPU 由**运算器和控制器**两大部分组成。运算器的核心是算术逻辑单元 **ALU**(Arithmetic Logic Unit),负责算术运算和逻辑运算,配套累加器 **AC**、数据缓冲寄存器 **DR**、状态条件寄存器 **PSW**。控制器负责取指、译码、发出控制信号,是指挥中心,核心是几个专用寄存器。

主要寄存器分工:程序计数器 **PC**(Program Counter)存放**下一条要执行指令的地址**,取指后自动加 1 指向下一条;指令寄存器 **IR**(Instruction Register)存放**当前正在执行的指令**;地址寄存器 **AR**(Address Register)保存当前访问的内存单元地址;数据寄存器 **DR**(Data Register)暂存从内存读出或要写入内存的数据。

指令格式:一条指令 = **操作码 + 地址码**。操作码指明做什么操作(加、减、传送),地址码指明操作数在哪里。按地址码个数可分为三地址、二地址、一地址和零地址指令。

**CISC** 与 **RISC** 对照:CISC(Complex Instruction Set Computer)复杂指令集,**指令数量多、长度可变**、功能复杂、寻址方式丰富,以**微程序控制**为主,代表是 x86;RISC(Reduced Instruction Set Computer)精简指令集,**指令数量少、长度固定**、争取单周期完成,提供大量通用寄存器,以**硬布线控制**为主,便于流水,代表是 **ARM、MIPS**。

> 考点提示:**PC 存的是地址不是指令,IR 存的才是指令本身**,这是经典陷阱题。题干说"为取下一条指令提供地址""跟踪程序执行过程"都选 PC。CISC 与 RISC 的特点对比也常年出现,记 RISC 的关键词:**指令少、定长、单周期、多寄存器、硬布线**。

## 寻址方式

寻址方式回答一个问题:指令中的地址码怎样换算成操作数的真实地址(**有效地址 EA**)。1. **立即寻址**:地址码就是操作数本身,取指即得数,**速度最快**,但操作数大小受地址码位数限制。2. **直接寻址**:地址码就是内存地址,EA = A,访问一次内存取数。3. **间接寻址**:地址码指向的内存单元里存的是操作数的地址,EA = (A),**至少访问两次内存**。4. **寄存器寻址**:操作数在寄存器中,**不访问内存**,速度快。5. **寄存器间接寻址**:寄存器中存的是操作数的内存地址,访问一次内存。6. **变址寻址**:EA = 变址寄存器内容 + 形式地址 A,适合遍历数组这类连续结构。

```text
指令示例 (假设内存 100 号单元存 500, 寄存器 R1 的值为 100):
MOV A, #30    立即寻址: 操作数就是 30
MOV A, 100    直接寻址: 取内存 100 号单元的内容, 得 500
MOV A, (100)  间接寻址: 100 号单元里是 500, 再取 500 号单元的内容
MOV A, R1     寄存器寻址: 取 R1 的值, 得 100
MOV A, (R1)   寄存器间接寻址: R1 的值是 100, 取 100 号单元的内容, 得 500
```

常考结论:执行速度最快的是**立即寻址**;取得操作数不需要访问内存的是**立即寻址和寄存器寻址**;适合数组元素访问的是**变址寻址**;**间接寻址比直接寻址多访问一次内存**。

## 流水线

流水线把一条指令的执行拆成若干段,各段并行处理不同的指令,像工厂的装配线。经典三段:**取指、分析、执行**。

核心结论:**流水线周期 Δt = 各段中最慢一段的耗时**;n 条指令的总执行时间 = **各段执行时间之和 + (n-1) × Δt**,也就是第一条指令走完全程,后面每条指令只多花一个周期。

```text
例题: 指令分取指、分析、执行三段, 分别耗时 2ns、2ns、1ns, 执行 100 条
1. 流水线周期 = max(2, 2, 1) = 2ns
2. 总时间 = (2 + 2 + 1) + (100 - 1) × 2
         = 5 + 198
         = 203ns
3. 顺序执行需要 100 × 5 = 500ns
4. 加速比 = 500 ÷ 203 ≈ 2.46
5. 吞吐率 = 100 ÷ 203ns ≈ 0.493 条/ns
```

**吞吐率 TP = 指令条数 ÷ 流水线总时间**,理论最大吞吐率 = **1/Δt**;**加速比 = 顺序执行时间 ÷ 流水执行时间**,段数越多、任务越多,加速比越接近段数。

> 考点提示:**流水线计算是上午必考题型**,公式别记反——**首条指令花全部段的时间,后续每条只花一个周期**。若题目给的是各段时间相等的理想流水线,可直接套 **n×Δt + (k-1)×Δt**(k 为段数)。算吞吐率时单位别丢,题目常把 ns 和 s 混着出。

通俗解释:流水线 ≈ 前端的打包流水线:loader 解析、plugin 转换、压缩输出三段同时处理不同文件,整体吞吐取决于最慢的那一段——所以优化构建要盯着最慢的 loader 下功夫,和"流水线周期取最慢段"是同一个道理。

## 存储系统

存储体系按速度从快到慢:**寄存器 → Cache → 主存 → 磁盘**。Cache 夹在 CPU 与主存之间,利用程序的**局部性原理**(时间局部性、空间局部性)缓存热点数据,**缓解 CPU 与主存的速度矛盾**。

### Cache 命中率

设命中率 h,Cache 存取周期 t1,主存存取周期 t2,则**平均访问周期 t = h×t1 + (1-h)×t2**。

```text
例题: Cache 周期 1ns, 主存周期 100ns, 命中率 0.95
平均周期 = 0.95 × 1 + 0.05 × 100
         = 0.95 + 5
         = 5.95ns
若命中率提高到 0.99: 0.99 × 1 + 0.01 × 100 = 1.99ns
可见未命中的那部分主导了平均开销
```

### 主存编址与芯片数量

**内存容量 = 末地址 - 首地址 + 1**,注意地址用十六进制表示,减完别忘加 1。**芯片数量 = 总容量 ÷ 单片容量**,位扩展(拼位宽)和字扩展(拼单元数)分开算。

```text
例题: 内存地址从 4000H 到 5FFFH, 用 8K×4 位的芯片构成, 需要几片?
1. 容量 = 5FFFH - 4000H + 1 = 2000H = 2 × 16^3 = 8192 个单元 = 8K
2. 按字节编址, 每个单元 8 位, 总容量 8K×8
3. 芯片数 = (8K × 8) ÷ (8K × 4) = 2 片 (位扩展, 两片拼出 8 位位宽)
若改用 4K×8 的芯片: (8K × 8) ÷ (4K × 8) = 2 片 (字扩展)
```

### 虚拟存储

虚拟存储把程序的逻辑地址空间和物理内存解耦,**解决容量矛盾**。**分页**是最常用的方式:把逻辑地址空间切成固定大小的页,内存切成同样大小的页框,**页表**记录页到页框的映射;为加速地址转换再配一块快表 **TLB**(Translation Lookaside Buffer)。访问的页面不在内存时触发**缺页中断**,由操作系统从磁盘调页。

类比前端:Cache 命中 ≈ 浏览器缓存命中——强缓存直接读本地、未命中才回源,命中率越高平均响应越快,平均访问周期公式和"命中率 × 本地读取耗时 + 未命中率 × 网络耗时"完全同构。虚拟内存分页则像路由级代码分割:页面按需懒加载,用到才调入内存,页表就是那份 chunk 清单。

> 考点提示:**Cache 平均周期、内存容量换算、芯片数量**是三件必考套,都是套公式的送分题,务必把十六进制减法练熟(如 5FFF - 4000 + 1 = 2000H)。概念上记住:**Cache 解决速度矛盾,虚拟存储解决容量矛盾**,别张冠李戴。

## 总线、中断与 DMA

总线分三类:**数据总线**传数据、双向;**地址总线**传地址、单向,**其位数决定可寻址空间大小**;**控制总线**传控制与状态信号。

I/O 控制方式由低到高分三档。1. **程序查询方式**:CPU 不断轮询设备状态,设备没准备好就原地干等,**CPU 利用率最低**。2. **中断方式**:CPU 发起请求后去干别的,设备准备好后主动发中断请求,CPU 暂停当前程序、保护现场,转去执行中断服务程序,完成后断点返回——CPU 与外设实现一定程度的并行。3. **DMA**(Direct Memory Access)直接存储器访问:数据在内存与外设之间**成块直接传送**,**全程不经过 CPU**,只在开始和结束时各中断一次,**速度最快**,适合磁盘这类高速块设备。

```text
三种方式对比:
程序查询: CPU 全程参与, 效率最低
中断方式: CPU 与设备并行, 但每次传送数据都要中断一次
DMA 方式: 成块传送不占用 CPU, 仅始末各中断一次, 效率最高
```

**中断向量是中断服务程序的入口地址**;CPU 响应中断前要先**保护现场**,保存程序计数器 PC 和程序状态字 PSW,返回时再恢复。

通俗解释:程序查询 ≈ 前端写死循环轮询接口;中断 ≈ 事件驱动,addEventListener 注册回调,事件来了再处理;DMA ≈ 浏览器让网卡把文件直接写进磁盘,主线程完全不被拖住。从轮询到事件再到旁路直达,就是一条"让 CPU 越来越不管闲事"的演进线。

## 可靠性与性能指标

### 可靠性计算

串联系统:任一部件失效则系统失效,可靠性 **R = R1 × R2 × ... × Rn**。并联系统:所有部件都失效系统才失效,**R = 1 - (1-R1)(1-R2)...(1-Rn)**。混联系统先把局部化简成等效部件,再套整体结构。

```text
例题: 三个部件的可靠性均为 0.9
串联: R = 0.9 × 0.9 × 0.9 = 0.729
并联: R = 1 - (1 - 0.9)^3 = 1 - 0.001 = 0.999
混联示例: 两个部件并联后再与第三个部件串联
         R = [1 - (1 - 0.9)^2] × 0.9 = 0.99 × 0.9 = 0.891
```

**MTBF**(Mean Time Between Failures)平均无故障工作时间,**MTTR**(Mean Time To Repair)平均故障修复时间,**系统可用性 = MTBF ÷ (MTBF + MTTR)**。

### 性能指标

**MIPS**(Million Instructions Per Second)表示每秒执行多少百万条指令,**CPI**(Cycles Per Instruction)表示每条指令平均需要多少时钟周期。二者换算关系:**MIPS = 主频 ÷ CPI**,注意主频要换算成 MHz。

```text
例题: 主频 2GHz, CPI = 4
MIPS = 2000 ÷ 4 = 500
即每秒执行 5 亿条指令
一条指令平均耗时 = 4 ÷ 2GHz = 2ns
```

记忆要点:**串联用乘法、并联用 1 减去全部失效的概率**,两个公式别背反;混联题先化简子系统再算整体。MIPS 与 CPI 的换算记住**主频除以 CPI**,题目给 GHz 先乘 1000 换成 MHz。
